# دانشنامه و نقطهٔ شیرجه زدن به پروژه‌ها

**dotdive** نقطه‌ای است برای این‌که قبل از شیرجه‌زدن به عمق هر پروژه، نقشه‌اش را ببینی. اینجا دانش هر پروژه به‌صورت مستندات تمیز و قابل‌جستجو نگهداری می‌شود.

## این‌جا چیست؟

- **مستندات عمومی** — دانش و راهنماهایی که برای همه باز است.
- **بلاگ** — نوشته‌ها و اخبار پروژه‌ها.
- **پروژه‌های خصوصی** — نقطهٔ شیرجهٔ تیم‌ها به مستندات داخلی، فقط با ورود.
