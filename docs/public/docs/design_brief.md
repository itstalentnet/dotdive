# Design Brief

## Llemu — AI Creative Studio

### 1. Project Overview

**Product:** Llemu
**Project Type:** UI Design
**Primary Platform:** Web
**Secondary Platform:** Mobile
**Existing Design System:** Available
**UX Research:** Defined in a separate document

---

# 2. Product Context

Llemu یک ابزار خلاقیت و طراحی مبتنی بر هوش مصنوعی است که تولید و ویرایش محتوای بصری را در یک محیط واحد ترکیب می‌کند.

محور اصلی محصول، یک **Interactive Canvas** است که کاربر می‌تواند در آن عناصر مختلف را ایجاد، قرار داده، ترکیب و ویرایش کند.

Llemu تلاش می‌کند فاصله میان ابزارهای سنتی طراحی و ابزارهای تولید محتوای مبتنی بر AI را کاهش دهد و امکان استفاده همزمان از **AI و کنترل دستی** را در یک محیط فراهم کند.

---

# 3. Design Objective

هدف طراحی UI این پروژه، تبدیل قابلیت‌ها و ساختار محصول Llemu به یک **رابط کاربری منسجم، قابل فهم و قابل استفاده** است.

رابط باید بتواند طیف مختلفی از قابلیت‌های محصول را بدون ایجاد پیچیدگی بصری غیرضروری در اختیار کاربر قرار دهد.

تمرکز اصلی طراحی بر این موارد است:

* وضوح عملکردها
* دسترسی مناسب به ابزارها
* حفظ تمرکز روی Canvas
* ایجاد ارتباط واضح میان قابلیت‌های AI و ابزارهای دستی
* حفظ تجربه یکپارچه در Web و Mobile

---

# 4. Target Users

Llemu برای گروه‌های مختلفی از کاربران طراحی می‌شود:

### Designers

کاربرانی که تجربه طراحی دارند و از Llemu برای ترکیب فرآیند طراحی با قابلیت‌های AI استفاده می‌کنند.

### Content Creators

کاربرانی که برای تولید محتوای بصری به ابزارهای سریع و انعطاف‌پذیر نیاز دارند.

### Marketers & Businesses

کاربرانی که برای تولید محتوای تبلیغاتی و بصری از ابزارهای طراحی و AI استفاده می‌کنند.

### General Users

افرادی که دانش تخصصی طراحی ندارند اما می‌خواهند ایده‌های بصری خود را ایجاد یا ویرایش کنند.

---

# 5. Core Product Experience

تجربه اصلی Llemu حول **Canvas** شکل می‌گیرد.

Canvas محیطی است که کاربر در آن می‌تواند:

* تصاویر و عناصر مختلف را قرار دهد.
* عناصر را جابه‌جا و ویرایش کند.
* خروجی‌های AI ایجاد کند.
* عناصر مختلف را با یکدیگر ترکیب کند.
* از ابزارهای دستی استفاده کند.
* از قابلیت‌های هوشمند برای تغییر و اصلاح استفاده کند.

Canvas باید مرکز اصلی تجربه طراحی باقی بماند و سایر قابلیت‌ها در خدمت فرآیند کار روی آن قرار بگیرند.

---

# 6. Core Product Areas

طراحی UI باید بخش‌های اصلی زیر را پوشش دهد.

## 6.1 Canvas

محیط اصلی طراحی و ویرایش.

شامل تعامل با:

* Text
* Shape
* AI-generated elements
* Node / Connections
* Layers
* Properties

## 6.2 Creative Guide

محیطی برای تولید سریع ایده و خروجی با استفاده از AI.

کاربر می‌تواند ایده خود را وارد کند و بر اساس آن خروجی‌های مختلف دریافت کند.

---

## 6.3 Manual Studio

محیطی برای ویرایش و کنترل دستی عناصر.

قابلیت‌های اصلی شامل:

* ایجاد Shape
* اضافه کردن Text
* اضافه کردن Image

* Resize
* Position
* Layer management
* تنظیم Properties

است.

---

## 6.4 AI Tools

ابزارهای عمومی AI که برای ایجاد یا اصلاح محتوای بصری استفاده می‌شوند.

قابلیت‌های تعریف‌شده در محدوده فعلی:

* Background Removal
* Upscale
* Style Transfer
* Text to Icon

---

## 6.5 Command Hub

محیط تعامل متنی با محصول.

کاربر می‌تواند از طریق Command Hub درخواست‌هایی برای تغییر یا ایجاد عناصر روی Canvas ارسال کند.

نمونه:

> کاهش سایه تصویر

> ایجاد یک کادر دور سوژه

---

## 6.6 Gallery

محیطی برای مشاهده و استفاده از:

* Templates
* Prompts
* نمونه‌های آماده

کاربر می‌تواند از یک نمونه موجود شروع کرده و آن را برای ایجاد خروجی جدید تغییر دهد.

---

## 6.7 Projects

محیط مدیریت پروژه‌های کاربر.

هر Canvas به عنوان یک Project در نظر گرفته می‌شود.

کاربر باید بتواند پروژه‌های خود را مشاهده و مدیریت کند.

---

## 6.8 Token

سیستم Token برای مدیریت استفاده از قابلیت‌های پردازشی AI.

کاربر باید بتواند میزان استفاده از Token و هزینه عملیات AI را در محیط محصول مشاهده و درک کند.

---

# 7. Platform Scope

### Web

Web پلتفرم اصلی Llemu است و کامل‌ترین تجربه محصول در این پلتفرم ارائه می‌شود.

### Mobile

Mobile نیز بخشی مهم از تجربه محصول است و طراحی باید برای استفاده در اندازه‌های کوچک و تعاملات لمسی در نظر گرفته شود.

Mobile صرفاً نسخه کوچک‌شده Web نیست و در طراحی UI باید محدودیت‌های فضای نمایش و نوع تعامل آن لحاظ شود.

---

# 8. UI Requirements

رابط کاربری باید:

* با Design System موجود محصول هماهنگ باشد.
* ساختار بصری منسجمی میان بخش‌های مختلف ایجاد کند.
* قابلیت‌های متعدد محصول را بدون ایجاد شلوغی غیرضروری نمایش دهد.
* وضعیت عناصر و ابزارهای فعال را به‌وضوح مشخص کند.
* تعاملات مربوط به Canvas را به شکل قابل فهم نمایش دهد.
* در Web و Mobile تجربه‌ای منسجم ارائه کند.
* تفاوت‌های تعامل Mouse / Keyboard و Touch را در نظر بگیرد.

---

# 9. Key Design Priorities

اولویت‌های اصلی طراحی UI عبارت‌اند از:

### Canvas First

Canvas باید مرکز توجه و مرکز تعامل محصول باشد.

### Clear Interaction

کاربر باید بتواند عملکرد ابزارها و وضعیت فعلی محیط را به‌سادگی تشخیص دهد.

### AI + Manual

قابلیت‌های AI و ابزارهای دستی باید در یک تجربه یکپارچه قرار بگیرند.

### Flexible

رابط باید بتواند هم نیاز کاربران حرفه‌ای و هم کاربران کم‌تجربه را پوشش دهد.

### Responsive

تجربه باید در Web و Mobile قابل استفاده و منسجم باشد.

---

# 10. Project Constraints

* Design System محصول از قبل تعریف شده است.
* پروژه در محدوده طراحی UI انجام می‌شود.
* Web پلتفرم اصلی محصول است.
* Mobile نیز در محدوده طراحی قرار دارد.
* UX Research در سند جداگانه تعریف می‌شود.
* جزئیات مربوط به فرآیند Research، Design System و مراحل اجرای پروژه در این Brief قرار نمی‌گیرد.

# 12. Brief Summary

Llemu یک ابزار خلاقیت مبتنی بر AI است که **Interactive Canvas** را به عنوان مرکز تجربه خود قرار می‌دهد و قابلیت‌های تولید AI، ویرایش دستی، ترکیب عناصر، ابزارهای هوشمند، Command Hub، Gallery و مدیریت پروژه را در یک محیط واحد ارائه می‌کند.

هدف طراحی UI، ایجاد یک تجربه واضح، منسجم و قابل استفاده برای این مجموعه قابلیت‌ها در **Web و Mobile** است؛ به‌گونه‌ای که Canvas همچنان مرکز اصلی تعامل کاربر باقی بماند و استفاده از قابلیت‌های AI و Manual در یک تجربه واحد امکان‌پذیر باشد.
