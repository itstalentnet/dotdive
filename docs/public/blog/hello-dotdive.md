# سلام dotdive!

به **dotdive** خوش آمدید — دانشنامه و نقطهٔ شیرجه‌زدن به پروژه‌ها.

## چرا dotdive؟

وقتی وارد یک پروژه‌ی جدید می‌شویم، بدترین بخش، پیدا کردن نقطهٔ شروع است. dotdive این نقطهٔ شیرجه را برای هر پروژه فراهم می‌کند:

- فهرستی تمیز از مستندات هر پروژه
- جستجوی فارسی و سریع
- دسترسی ساده به محتوای خصوصی تیم‌ها

## چه چیزهایی در راه است؟

- بلاگ و مستندات عمومی
- پروژه‌های خصوصی با ورود گوگل و ایمیل
- جستجوی هوشمند
