## قانون سلسله‌مراتب (Hierarchy Rule)

نقش‌های تایپوگرافی یک آبشار نزولیِ سخت‌گیرانه می‌سازند. هر نقش باید در سطح درست خود قرار
گیرد. **ترتیب از اندازهٔ دقیق مهم‌تر است.**

```text
Display
   ↓
Title
   ↓
Subtitle
   ↓
Body
   ↓
Utility   (Label / Navigation / Button)
   ↓
Meta      (Caption / Placeholder)
```

| سطح | نقش‌ها | هدف |
|-------|-------|---------|
| Display | `display.*` | هیروها، تیترهای صفحه، متریک‌های بزرگ |
| Title | `title.*` | تیتر بخش / کارت / آیتم |
| Subtitle | `subtitle.*` | متن پشتیبان دقیقاً زیر یک تیتر |
| Body | `body.*` | متن خواندنی / UI پیش‌فرض |
| Utility | `label`, `navigation`, `button` | متن تعاملی / ساختاری UI |
| Meta | `caption`, `placeholder` | کوچک‌ترین متن توصیفی / راهنما |

یک نقش **هرگز** نباید از سطح بالاتر از خود بزرگ‌تر باشد. وقتی یک محصول به یک گام بزرگ‌تر
نیاز دارد، یک بسط (`xl`، `hero`، `lg`) *بالای* سطح خود اضافه می‌کند — آبشار را نمی‌شکند.

## نسبت تایپوگرافی (استاندارد سازمان)

اندازه‌ها بر اساس حس انتخاب **نمی‌شوند**. هر نقش مقدار ثابتی به‌ازای هر تم دارد که از یک
مقیاس متناسب واحد مشتق شده است تا سه محصول از نظر بصری هم‌گون باقی بمانند.

| نقش | Dashboard | Shop | Blog |
|------|-----------|------|------|
| Display | ۳۰ | ۳۶ | ۴۲ |
| Title LG | ۲۲ | ۲۴ | ۳۲ |
| Title MD | ۱۷ | ۲۰ | ۲۴ |
| Subtitle | ۱۵ | ۱۶ | ۱۸ |
| Body | ۱۴ | ۱۴ | ۱۴ |
| Label | ۱۳ | ۱۳ | ۱۳ |
| Button | ۱۴ | ۱۴ | ۱۴ |
| Caption | ۱۲ | ۱۲ | ۱۲ |

### قوانین مشتق‌شده از نسبت

* **توکن‌های پایدار** — `Body`، `Label`، `Button`، `Caption` در همهٔ محصولات یکسان‌اند.
  آن‌ها الگوهای UI مشترک را نمایندگی می‌کنند و فقط با دلیل usability قوی تغییر می‌کنند.
* **توکن‌های مقیاس‌یافته** — `Display` / `Title` / `Subtitle` با شخصیت هر محصول رشد
  می‌کنند (Dashboard = فشرده، Blog = گسترده) در حالی که همان گام متناسب را حفظ می‌کنند.
* **بسط‌ها (Extensions)** — `display.hero`، `title.xl`، `subtitle.xl`، `body.lg` بالای
  سطح پایهٔ خود نشسته‌اند و همان گام را دنبال می‌کنند (مثلاً `title.xl` > `title.lg` > `title.md`).
* **نام مستعار (Alias)** — `placeholder` نام مستعارِ `caption` است (هم‌اندازه/هم‌وزن؛ فقط
  opacity متفاوت است که توسط توکن‌های رنگ مدیریت می‌شود). یک اندازهٔ جداگانه نیست.
* **بدون مقادیر خام در تم‌ها** — هر مقدار به یک اولیهٔ Registry ارجاع می‌دهد
  (`fs-*`، `fw-*`، `lh-*`، `ls-*`). یک تنظیم مجدد (retune) واحد در Registry، هر سه محصول را
  دگرسازی (re-skin) می‌کند.
