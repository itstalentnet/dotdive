# مستندات مرجع پلتفرم نونز (Nons Documentation)

**نونز (Nons)** یک پلتفرم بازارچه توزیع‌شده و رویدادمحور برای تبادل کالاهای دیجیتال و بازی است که خریداران و فروشندگان را در محیطی امن، مبتنی بر چت بلادرنگ، پرداخت با ضمانت و سیستم داوری به یکدیگر متصل می‌کند.

---

برای مطالعه آسان و جهت‌یابی سریع، کلیه اسناد فنی بر اساس حوزه‌های مهندسی زیر سازماندهی شده‌اند:

| بخش | مسیر دسترسی | توضیحات و محتوا |
| :--- | :--- | :--- |
| 📋 **معرفی و بلوپرینت کلان** | [`01-overview/`](./01-overview/) | بلوپرینت جامع سیستم، پروپوزال، اهداف کسب‌وکار و نیازمندی‌های کلان پلتفرم |
| 🏛️ **معماری پلتفرم و هسته** | [`02-platform/`](./02-platform/) | معماری کلان، Core، Gateway، پکیج‌های اشتراکی، قراردادهای رویداد و استانداردهای مهندسی |
| ⚙️ **سرویس‌ها و بک‌اند** | [`03-backend/`](./03-backend/) | سرویس‌های ۹‌گانه (احراز هویت، کیف پول، توکن، استوریج...)، دیاگرام‌های جریان داده و راهنماها |
| 💻 **توسعه فرانت‌اند و دیزاین** | [`04-frontend/`](./04-frontend/) | معماری کلاینت، الگوی رجیستری، توکن‌های دیزاین، وضعیت‌های تعاملی و راهنمای توسعه‌دهنده |

## 🚀 از کجا شروع کنیم؟

- **برای درک چشم‌انداز و نقشه کلی:** سند [**بلوپرینت نهایی پلتفرم**](./01-overview/blueprint.md) را مطالعه کنید.
- **برای توسعه‌دهندگان بک‌اند:** بخش [**سرویس‌های بک‌اند**](./03-backend/) و [**هسته پلتفرم**](./02-platform/core/) را بررسی کنید.
- **برای توسعه‌دهندگان فرانت‌اند:** بخش [**معماری فرانت‌اند**](./04-frontend/) و راهنمای دیزاین سیستم را مطالعه کنید.
- **برای مهندسان زیرساخت:** بخش [**استقرار و دوآپس**](./05-devops/) را مشاهده کنید.
