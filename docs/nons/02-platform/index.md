# معماری پلتفرم و هسته سیستم (Platform Architecture)

این بخش شامل مستندات زیرساختی سطح پلتفرم، هسته مرکزی، استانداردهای کدنویسی و معماری ارتباطات رویدادمحور در نونز است.

## سرفصل‌های اصلی پلتفرم

### هسته و معماری کلان
- **[معماری کلان سیستم (Architecture)](./Architecture.md)**: ساختار لایه‌ای و توپولوژی سرویس‌های پلتفرم
- **[مدل مجوزها و دسترسی‌ها (Permission Model)](./permission-model.md)**: معماری کنترل دسترسی مبتنی بر نقش و مجوز
- **[جریان سفارش، پرداخت و کیف پول](./order-payment-wallet-flow.md)**: فرآیند مرحله‌به‌مرحله پرداخت، مسدودی وجه و تسویه حساب
- **[هسته پلتفرم (Core)](./core/)**: مشخصات و معماری هاب رویدادها و سرویس‌های مرکزی
- **[درگاه ارتباطی (Gateway)](./gateway/)**: معماری API Gateway، مسیریابی و کنترل ترافیک

### قراردادها و توسعه
- **[پکیج‌های اشتراکی و قراردادها (Packages)](./package/)**: کاتالوگ پکیج‌های مشترک، رویدادها و تایپ‌ها
- **[استانداردهای طراحی API](./api/)**: راهنمای OpenAPI، طراحی REST و تولید خودکار SDK
- **[استانداردهای مهندسی پلتفرم](./standards/)**: سیاست‌های Git، امنیت، لاگینگ، تست و نسخه‌بندی
- **[دیاگرام‌های معماری پلتفرم](./diagrams/)**: دیاگرام‌های کانتینری و معماری رویدادمحور (EDA)
- **[سوابق تصمیمات معماری (ADR)](./ADR/)**: تصمیمات کلیدی سطح پلتفرم
