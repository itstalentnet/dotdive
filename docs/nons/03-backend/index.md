# معماری سرویس‌ها و بک‌اند (Backend Services)

این بخش شامل مستندات پیاده‌سازی سرویس‌های پشتیبان، پایگاه‌های داده، دیاگرام‌های گردش داده و الگوهای مدیریت خطا در نونز است.

## سرفصل‌های اصلی بک‌اند

### راهنماها و شروع کار
- **[شروع سریع بک‌اند (Get Started)](./get-started.md)**: راه‌اندازی محیط توسعه، ابزارها و اولین اجرا
- **[یکپارچه‌سازی پنل مدیریت (Admin Panel)](./admin-panel-integration.md)**: تعامل سرویس‌ها با پنل مدیریتی
- **[استراتژی مدیریت خطاها (Error Handling)](./error-handling-strategy.md)**: استانداردهای گزارش‌دهی و مدیریت خطاهای سیستمی
- **[راهنمای رفع اشکال (Troubleshooting)](./troubleshooting.md)**: راهنمای عیب‌یابی خطاهای متداول سرویس‌ها
- **[نقشه راه بک‌اند (Roadmap)](./roadmap.md)**: اولویت‌ها و اهداف توسعه بک‌اند

### سرویس‌ها و قراردادها
- **[سرویس‌های تخصصی (Services)](./services/)**: مستندات سرویس‌های احراز هویت (`auth`)، هویت سازمانی (`iam`)، ارز و دارایی (`currency`)، استخر سفارشات (`pool`)، تسویه حساب (`settlement`)، ذخیره‌سازی (`storage`)، توکن (`token`) و کاربران (`user`).
- **[دیاگرام‌های گردش داده (Diagrams)](./diagram/)**: فلوهای احراز هویت، حل اختلاف، مدیریت سفارش، تعدیل و انتشار محصول.
- **[استانداردهای بک‌اند (Standards)](./standard/)**: فرمت واحد پاسخ‌های API و کدهای استاندارد HTTP.
- **[تصمیمات معماری بک‌اند (ADR)](./ADR/)**: سوابق تصمیم‌گیری‌های فنی تیم بک‌اند.
