# معماری و تصمیمات کلان پروژه لیمو (Lemmo)

این بخش مرجع اصلی اصول مهندسی، مرزهای لایه‌ای و تصمیمات اتخاذ شده در سیستم لیمو است.

## سرفصل‌های این بخش

- **[پروتکل و راهنمای عملیاتی ایجنت‌ها (AGENTS.md)](./AGENTS.md)**: قوانین، محدودیت‌ها، نحوه استناد به اسناد و رفتار ایجنت‌های هوش مصنوعی در کدنویسی لیمو.
- **[استراتژی جامع مدیریت پیکربندی و رمزهای عبور (DOC-ARCH-009)](./configuration-and-secrets.md)**: دسته‌بندی سه‌گانه متغیرها، الزام توقف فوری (Fail-Fast)، منع ثوابت هاردکد و فایل‌های کانفیگ YAML.
- **[ممیزی امنیتی پلتفرم، کاتالوگ تهدیدات و برنامه جامع مقاوم‌سازی (DOC-ARCH-010)](./security-audit-and-remediation.md)**: تحلیل تفصیلی ۲۲ یافته ممیزی امنیتی (P0/P1/P2)، کاتالوگ تهدیدات و برنامه ۴ جریانی رفع آسیب‌پذیری‌ها.
- **[تصمیمات رسمی معماری (Architecture Decision Records)](./decisions/)**: ثبت رسمی تصمیمات کلیدی معماری، دلایل انتخاب و گزینه‌های ردشده.

## اصول کلیدی معماری

1. **منبع یگانه حقیقت (SSOT)**: هر توکن دیزاین، رابط API و قرارداد داده‌ای دقیقاً در یک نقطه تعریف می‌شود.
2. **پیمانه‌ای بودن (Modularity)**: ماژول‌های استودیو لیمو به صورت ایزوله و مستقل از یکدیگر طراحی شده‌اند.
3. **سازگاری با هوش مصنوعی**: کدها و متادیتاها برای مصرف بهینه توسط مدل‌های زبانی ساختار یافته‌اند.
