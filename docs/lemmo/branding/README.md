# هویت برند و دارایی‌های بصری (Branding & Identity)

این بخش به عنوان راهنمای جامع برندینگ **Lemmo**، قوانین استفاده از لوگو، نشان اختصاصی (Triad Mark)، ترکیب رنگی و فایل‌های مرجع دارایی‌های بصری را مشخص می‌کند.

## قوانین اساسی برند
1. **نشان سه‌نقطه‌ای (3-Dot Triad Mark):**
   - نماد اختصاصی برند Lemmo شامل ۳ نقطه دایره‌ای با چیدمان مثلثی متقارن است.
   - هرگونه تغییر زاویه، تغییر فاصله یا حذف/اضافه کردن نقطه‌ها ممنوع است.
2. **پالت رنگی برند:**
   - رنگ اصلی اکشن برند: لایم پرانرژی (`#D1FE17`) در پس‌زمینه‌های تاریک.
   - رنگ معکوس متن روی لایم: مشکی سیر (`#131517`) جهت رعایت دسترسی‌پذیری و کنتراست استاندارد WCAG AA.
3. **فاوآیکون و نشان‌ها:**
   - فاوآیکون رسمی نسخه رستر و بهینه‌شده در فایل `favicon.ico` قرار دارد.
