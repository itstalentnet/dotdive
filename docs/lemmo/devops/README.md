# زیرساخت و دوآپس (DevOps & Infrastructure)

این پوشه شامل کلیه مستندات مربوط به مدیریت زیرساخت، خطوط خودکار یکپارچه‌سازی و استقرار مداوم (CI/CD)، مانیتورینگ، امنیت شبکه و متغیرهای محیطی است.

## سرفصل‌های اصلی این بخش
- **پایپ‌لاین‌های CI/CD (GitHub Actions / GitLab CI):** قوانین اعتبارسنجی Pull Requestها شامل لینت، تست اتوماتیک، بررسی تایپ‌ها و تست‌های بیلد.
- **کانتینرسازی و داکر (Docker & Compose):** فایل‌های Dockerfile چندمرحله‌ای (Multi-stage build) برای محیط‌های توسعه و پروداکشن.
- **استراتژی استقرار (Deployment Strategy):** نحوه انتشار نسخه‌های فرانت‌اند و لندینگ روی Edge / CDN و انتشار سرویس‌های بک‌اند.
- **مدیریت محرمانه‌ها (Secrets & Environments):** شیوه‌نامه نگهداری کلیدهای API و فایل‌های `.env` به شکل امن بدون کامیت در مخازن کد.
