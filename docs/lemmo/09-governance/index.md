# قوانین حاکمیت پروژه و استانداردهای مستندنویسی (Governance)

این بخش شامل اصول طلایی، قوانین لازم‌الاجرا و تمپلیت‌های مرجع پروژه لیمو است که رعایت آنها برای تمام اعضای تیم و ایجنت‌های هوش مصنوعی الزامی است.

## اسناد این بخش

- **[قوانین توسعه و ضدتضاد (RULE.md)](./rules.md)**: قوانین اصل طلایی SSOT، پروتکل توقف در صورت تضاد و الزامات یکپارچگی کد.
- **[الگوی استاندارد اسناد (Document Template)](./document-template.md)**: قالب آماده شامل جدول متادیتای الزامی بالای هر سند برای پارس آسان توسط انسان و مدل‌های زبانی.
