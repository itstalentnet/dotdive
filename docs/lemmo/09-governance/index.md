# قوانین حاکمیت پروژه و استانداردهای مستندنویسی (Governance)

این بخش شامل اصول طلایی، قوانین لازم‌الاجرا، ماتریس تصمیمات معماری، مسیر جاری MVP و الگوهای مرجع پروژه لیمو است که رعایت آنها برای تمام اعضای تیم و ایجنت‌های هوش مصنوعی الزامی است.

## اسناد محوری مسیر جاری MVP

- **[مسیر جاری اجرای MVP و زنجیره طلایی (DOC-GOV-003)](./current-path.md)**: زنجیره طلایی تجربه کاربر، اولویت‌بندی اجرایی پنج‌گانه (D-15)، مسیرهای موازی و ماتریس وضعیت ۴ سطحی قابلیت‌ها.
- **[ماتریس رسمی تصمیم‌های معماری و حاکمیتی MVP (DOC-GOV-004)](./decision-register.md)**: جدول وضعیت رسمی تصمیمات D-01 تا D-15 و پیگیری موارد باز P-1 تا P-6.
- **[استانداردهای مهندسی تسک و قواعد بازبینی مستقل (DOC-GOV-005)](./task-template-and-review-rules.md)**: استانداردهای تدوین تسک، معیارهای وضعیت‌ها، خطوط قرمز مانع لانچ و وظایف ناظر مستقل.
- **[سند تصمیم‌ها و مسیر اجرایی لیمو (مرجع تسک‌ها)](./mvp-decision-register.md)**: سوابق تفصیلی جلسه برنامه‌ریزی، پیشینه تصمیمات، تعارض‌ها و افق‌های فازبندی.

## اسناد پایه‌ای حاکمیت و استانداردها

- **[قوانین حاکمیتی و ضدتضاد ایجنت‌ها (DOC-META-002)](./rules.md)**: قوانین اصل طلایی SSOT، پروتکل توقف فوری در صورت تضاد (STOP Protocol) و الزامات یکپارچگی مستندات.
- **[الگوی استاندارد اسناد (Document Template)](./document-template.md)**: قالب آماده شامل جدول متادیتای الزامی بالای هر سند برای پارس آسان توسط انسان و مدل‌های زبانی.
